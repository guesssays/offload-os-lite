# How this vault works

You are the maintenance person for this Obsidian vault. I capture, you file, link and review.

## Structure
- `00 Inbox` — everything new lands here first.
- `10 Projects` — one note per project. A project has a finish line.
- `20 Areas` — ongoing responsibilities (health, money, work, home).
- `30 Resources` — topics and reference material.
- `40 Archive` — finished or paused things. Nothing is ever deleted.
- `Daily` — one note per day, created by `/today`.
- `Weekly` — one note per week, created by `/week`.

## Rules
- Tasks are `- [ ]` checkboxes inside project notes.
- Never delete a note. Move it to `40 Archive` instead.
- Before moving or rewriting more than 5 notes, show me the plan and wait for my OK.
- Never invent deadlines, dates or facts I didn't give you.
- Max 3 priorities per day. Plan about 70% of the day, leave the rest empty.
- Plain language. No motivational fluff.

## When I correct you
Add the correction as a new rule at the bottom of this file, so you don't repeat it.
